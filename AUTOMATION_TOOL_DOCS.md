## 💡 Key Concepts

### **Modes**
- Shop mode: `http://localhost:3001` (original)
- Automation mode: `http://localhost:3001?mode=automation` (new tool)

### **4 Core Pages**
1. **Home** - Landing page to sell the product
2. **Auth** - Signup and login forms
3. **Dashboard** - Order management interface
4. **AutomationApp** - Router between all pages

### **Features**
- Real-time filtering by status
- Search by customer name/phone
- Order detail view
- Status update buttons
- Responsive design
- Mock data for testing
